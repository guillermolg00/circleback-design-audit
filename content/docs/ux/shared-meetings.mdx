---
title: Shared meetings
description: Features disappear without explanation when the meeting isn’t yours.
---

<Sev level="high" />

<Finding>
  <What>
    A shared meeting is missing the Notes and Transcript tabs, “Add tag”, and “+ Add” in action items. Nothing explains why. The “…” menu changes too (see [Menus per object](/docs/ux/menus)).
  </What>
  <Why>
    The same page looks different depending on who opens it, and the user can’t tell whether something is missing, broken, or off-limits to them.
  </Why>
  <Proposal>
    Always show the same structure. Anything unavailable is shown disabled with the reason (“The owner didn’t share the transcript”) and, when it applies, an action to request it.
  </Proposal>
</Finding>
