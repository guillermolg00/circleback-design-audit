---
title: Dead-end errors
description: Recording errors only offer to delete the meeting.
---

<Sev level="high" />

<Finding>
  <What>
    In the list, 5 of 8 visible rows are errors (“wasn’t allowed in”, “couldn’t pick up any conversation”, “error processing”). The only action is a red *Delete*, and at 800px wide it gets cut off (“Del”) or disappears. In the detail view, the notice isn’t clickable and the page is left empty. Three rows have the same name (“New meeting”).
  </What>
  <Why>
    The user doesn’t know whether the problem will happen again or how to avoid it. The failed recurring meeting stays toggled on in Home with no warning, and the only suggested action is destructive.
  </Why>
  <Proposal>
    Each error gets its cause and one primary action: retry, upload the recording, or see how to admit the bot in Zoom, Meet, or Teams. Delete moves into the menu. Add a warning on the next occurrence of the recurring meeting, and use default titles with the date and time.
  </Proposal>
</Finding>
