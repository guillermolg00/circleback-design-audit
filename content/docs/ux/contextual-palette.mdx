---
title: Context-blind command palette
description: The command palette navigates and searches, but offers no actions on the open object and shows no shortcuts.
---

<Sev level="high" />

<Finding>
  <What>
    Inside a meeting, searching “share” returns “Copy referral link”, not “Share this meeting”. ⌘K navigates well (Settings sections included) and lets you hand off to the AI with Tab, but it offers no actions on the open object, and no command shows its shortcut.
  </What>
  <Linear>
    ⌘K puts actions on the current object first (change status, assign, copy link) and shows the shortcut to the right of each command, which teaches the keyboard as you go.
  </Linear>
  <Proposal>
    Add a “This meeting” group at the top, with Share, Add tag, Automations, Copy link, and Delete, and show the shortcut on every command. Do the same for a selection in the list.
  </Proposal>
</Finding>
