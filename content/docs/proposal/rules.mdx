## How to maintain it

- A component inventory with its allowed variants, in the repository, next to the theme.
- An automated CI check that flags off-scale radii, heights, and colors. This audit’s measurement script (getComputedStyle on the rendered app) is a starting point.
- A review rule: a new value requires a new token, and a new token requires a written reason.
