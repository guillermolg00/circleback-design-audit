## Current

The base rhythm in Settings is good and stable: **27px from the title to the first label, 15px from the label to the card, and 43px from one card to the next section**. The problem is that two templates coexist. Account, Preferences, and Calendar use a section label (15px, weight 500). Emails, Sharing, and Tags use a page description (14px, weight 500) 6px below the title, with unlabeled cards.

<Finding>
  <Rule>Every Settings section has a label; the description is optional and goes below the label, not below the page title. Rows share a minimum height (56, content centered), padding (8/16), type (14/12), and divider (subtle). The page’s horizontal padding goes from 40 to 64, like the rest of the app.</Rule>
