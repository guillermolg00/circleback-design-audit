## Current

The popovers (the “…” menu, right-click, account, Filter, New meeting) use radius 6 and a 1px #3E3E3E border. Even so, item height and container padding change from one to the next. Palettes and dialogs belong to a different family, documented in [Command palette and dialogs](/docs/components/palette-and-dialogs).

<Finding>
  <Rule>Every popover shares the same container (md, padding 4, subtle border) and the same item (32px, sm, 16px icon 8px from the text). The account menu drops its 4px 0 vertical padding; Filter gains padding 4; New meeting goes from 58 to 48 and brings the icon closer to the text. Each item shows its shortcut if it has one.</Rule>
</Finding>
