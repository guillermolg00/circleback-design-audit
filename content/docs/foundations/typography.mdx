## Current

Circleback uses the system font for the interface and **Plus Jakarta Sans 700** only for page titles. That’s a good call and it stays. The problem is the number of combinations.

## Proposal

Eight styles, each with a single line height and a default weight. Document text (notes and transcript) shares one style.
