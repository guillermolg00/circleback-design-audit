## Proposal

Five tokens, each with a clear role. Values that go away are struck through.

<Scale values={[4, 6, 7, 8, 10, 12, 15, 16, 'pill']} add={[8]} drop={[6, 7, 10, 15]} />

  <RadiusSwatches

      { r: 12, label: 'md · card, popover, row hover' },

      { r: 999, label: 'full · chip, tab, avatar' },

      { r: 15, label: '→ 16', drop: true },
    ]}
  />
</Story>

<Finding>
  <Rule>A control (button, input, item) uses **sm**. A surface that holds controls (card, popover, row hover) uses **md**; a card nested inside another steps down to **sm**. A surface that holds surfaces (command palette, dialog) uses **lg**, and so does the Ask bar. Nothing that opens from a button has a smaller radius than the button.</Rule>
</Finding>
